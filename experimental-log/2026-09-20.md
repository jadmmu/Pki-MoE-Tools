# Experimental log

## Phase 1 reconnaissance

The workspace had no project files, no accessible Python runtime, and no installed PyTorch or Transformers packages. The OLMoE checkpoint configuration identifies 16 routed layers, 64 experts, and top-8 routing. Transformers exposes a passive router hook path at `model.model.layers[i].mlp.gate`; its return values are router logits, selected weights, and selected IDs. Token mapping during prefill and cached decode remains unresolved.

## Phase 2 architecture decisions

The project uses one canonical JSON trace format and one manifest format for both execution conditions. Backend-specific code stops at trace-source capture. Synthetic traces are explicitly marked and are never treated as experimental observations. The first visualization consumes stored traces only.

The initial schema uses nullable raw quantities and preserves event order plus source tensor shapes. It does not infer token positions from callback order.
